§5.3

Reply rules

TypeBody 16/1.6. Headings inside replies use Heading 3 (Inter 600 18), never Bebas: Bebas is for the app, not the model's words.
Spacing12 px between paragraphs and blocks, 24 px before a heading or a framed block. Reply width = column width.
FramesAnything you can act on, or anything from outside (web, files, apps), gets a 1 px border. Plain text gets none.
SourcesNumbered boxed markers in the text, a numbered list under a hairline. Site name shown in grey. Links open in a new tab and say so to screen readers.
ChartsTitle (H3) + a one-sentence takeaway. Four greys with patterns, direct labels, horizontal grid only. "Show as table" under every chart.
Tables44 px rows, hairline between, strong rule under the header. Numbers right-aligned, tabular. Wide tables scroll inside a labelled, focusable box with a sticky first column.
FormsLabels above, help below, errors below with an icon. One primary submit. After sending: fields read-only, button reads "Sent" with a check and is disabled.
CalloutsBordered box led by an icon and a word: Note, Tip, Warning. Warning uses the warning colour for icon and word only.
MetricsLabel (13 600) above, number in Inter 600 32 tabular, change as text ("up 4 from last week").
Tabs, stepsTabs underline 2 px. Steps are a numbered list with a status word per step, not a coloured line.
Images, videoSquare-cornered grid, 4 px gaps, caption with the source site. Video links show duration and site; they open outside.
